{# xhtml2pdf (ReportLab) template - the rendered Markdown, and nothing else. Same contract as `pdf/document.html`: no title block, no metadata line, no running header or footer, no page number. What the document does not say itself does not reach the page. This engine understands only a subset of CSS, so the layout is rebuilt with the constructs it does support: base-14 font names instead of a font stack, no flexbox, no grid, no break-inside. With the running frames gone, the whole page is one flow, which is also the shape this engine handles best. Visual fidelity is deliberately lower than the WeasyPrint template - see the README section "Dependências do WeasyPrint" for how to enable the full one. #} {{ document.display_title }} {{ printable_html | safe }}
